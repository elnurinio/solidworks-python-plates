# SolidWorks Plate Generator

Учебный проект: Python-скрипт, который по заданным параметрам автоматически строит в SolidWorks пластину с рядом отверстий и сохраняет её в файл `.SLDPRT`.

## Что делает скрипт

- создаёт новую деталь через SolidWorks API
- рисует эскиз: прямоугольник и ряд отверстий
- выдавливает пластину на заданную толщину
- сохраняет деталь в папку `C:\sw_project\parts`

## Параметры

Функция `make_plate(name, length, width, height, n_holes, hole_d, step)`. Все размеры в метрах.

| Параметр | Что означает |
|----------|--------------|
| `name` | имя файла без расширения |
| `length` | длина пластины |
| `width` | ширина пластины |
| `height` | толщина пластины |
| `n_holes` | количество отверстий |
| `hole_d` | диаметр отверстия |
| `step` | расстояние между центрами отверстий |

## Требования

- Windows
- SolidWorks (проверено на версии 2022)
- Python 3
- библиотека pywin32: `python -m pip install pywin32`

## Запуск

1. Запустить SolidWorks.
2. В командной строке выполнить:

```
python plate_save.py
```

## Пример вызова

```python
make_plate("plate_1", 0.08, 0.05, 0.01, 3, 0.008, 0.02)
```

Получится пластина 80 × 50 × 10 мм с тремя отверстиями диаметром 8 мм.
